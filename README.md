# Windows-AclInspector
I'm a newly registered GitHub user, and this is my first project. It may have many issues, so please bear with me while I introduce it.A lightweight Windows tool to scan directory ACLs and highlight common permission issues like orphaned SIDs, explicit deny rules, and Everyone: Full Control. Built in C#, runs on Windows 10/11 with no dependencies.
For more details, please refer to the user guide included in the package.
